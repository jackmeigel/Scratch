# GitHub Issue Triage Demo

This is a demo repository created to showcase various types of GitHub issues that need triaging. The repository contains a simple web application with intentional issues and feature requests to demonstrate issue management workflows.

## Project Overview

This project is a task management web application built with:
- Frontend: React + TypeScript + Tailwind CSS
- Backend: Node.js + Express
- Database: SQLite
- Testing: Jest + React Testing Library

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Run tests
npm test

# Build for production
npm run build
```
